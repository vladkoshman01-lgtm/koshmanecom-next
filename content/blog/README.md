# Статті блогу

Одна стаття — один файл `.md` у цій папці. Ім'я файлу стає адресою:
`content/blog/yak-prodavaty-na-etsy.md` → `https://koshmanecom.com/blog/yak-prodavaty-na-etsy`

Називай файли латиницею, малими літерами, через дефіс — це і є SEO-адреса сторінки.

## Мови

- `slug.md` — українська (адреса `/blog/slug`)
- `slug.en.md`, `slug.sk.md` — переклади тієї ж статті. Залиш той самий `slug`,
  тоді сторінки автоматично звʼяжуться через hreflang.

## Картинки

Клади в окрему папку статті: `public/blog/<slug>/`.

- Обкладинка — банер **1200×630** (краще 2400×1260 для чітких екранів) у `.webp`.
  Пропорцію не змінюй: картки й велика картка у списку показують її цілою.
- Для соцмереж додай JPG 1200×630 і вкажи його в `ogImage`
  (Facebook і LinkedIn не всюди розуміють WebP).
- Картинки в тексті: `![Опис картинки для Google](/blog/<slug>/назва.webp)` окремим рядком.

## Шаблон

```markdown
---
title: Як вийти на Etsy у 2026 році
excerpt: Коротко про те, з чого почати і скільки це коштує. Цей текст показується у списку статей і в пошуку Google.
date: 2026-10-16
author: Влад Кошман
category: Etsy
tags: [etsy, старт]
cover: /blog/etsy-start.jpg
coverAlt: Вітрина магазину на Etsy
---

Перший абзац.

## Підзаголовок

Текст, **жирний**, [посилання](https://example.com), списки:

- перший пункт
- другий пункт
```

## Поля

| Поле | Обовʼязкове | Що це |
|---|---|---|
| `title` | так | Заголовок статті |
| `date` | так | Дата публікації, формат `РРРР-ММ-ДД`. За нею сортується список |
| `excerpt` | ні | Опис для списку статей і для Google. 1–2 речення |
| `author` | ні | Імʼя автора |
| `category` | ні | Категорія, напр. `Etsy`, `Shopify`, `Реклама` |
| `tags` | ні | Теги списком у квадратних дужках |
| `seoTitle` | ні | Заголовок для Google, якщо коротший за H1 (`title`) |
| `cover` | ні | Обкладинка, шлях `/blog/<slug>/cover.webp` |
| `coverAlt` | ні | Опис обкладинки для доступності й SEO |
| `coverWidth`, `coverHeight` | ні | Розміри обкладинки в пікселях (щоб сторінка не «стрибала» при завантаженні) |
| `ogImage` | ні | Картинка для соцмереж, JPG 1200×630. Без неї береться `cover` |
| `authorRole`, `authorPhoto`, `authorBio` | ні | Посада, фото (`/team/Vlad.png`) і коротко про автора — блок «Про автора» |
| `keywords` | ні | Ключові слова списком — потрапляють у метадані й розмітку статті |
| `updated` | ні | Дата оновлення `РРРР-ММ-ДД`, якщо статтю переписали |
| `draft` | ні | `true` — стаття не публікується і не потрапляє в сітмап |

Час читання рахується автоматично з обсягу тексту. Зміст збоку будується із заголовків `##`,
а розділ `## Часті запитання` (питання — `###`) автоматично стає FAQ-розміткою для Google.
Джерела окремим списком не публікуємо: посилання на офіційні сайти ставимо прямо в тексті, на словах,
яких вони стосуються (`режим [One Stop Shop](https://...)`). Так і читати зручніше, і Google бачить довіру до тексту.

## Як опублікувати

1. Створи файл у цій папці.
2. Перевір локально: `npm run dev`, відкрий `/blog`.
3. Закоміть і задеплой — стаття стане окремою HTML-сторінкою.
